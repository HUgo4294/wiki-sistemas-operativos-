En esta unidad se estudian los conceptos fundamentales de los sistemas operativos, su función dentro de una computadora, los recursos que administran, la relación entre hardware y software, los modos de ejecución del procesador, las llamadas al sistema y las principales arquitecturas de los núcleos.

Comprender estos conceptos permite conocer cómo trabaja internamente una computadora y cómo el sistema operativo coordina los diferentes componentes para que los programas puedan ejecutarse de manera segura y eficiente.
---
## 1. ¿Qué es un Sistema Operativo?
Un **Sistema Operativo (SO)** es el software fundamental que administra los recursos físicos y lógicos de una computadora.

Actúa como intermediario entre:

- El usuario.

- Los programas.

- El hardware.

Su función principal es facilitar el uso de la computadora y controlar todos los recursos disponibles.

Podemos representarlo de la siguiente manera:

<div className="u1-diagram">
  <pre>{`+-----------------------------+

|           USUARIO           |

+-----------------------------+

              |

              ↓

+-----------------------------+

|        APLICACIONES         |

+-----------------------------+

              |

              ↓

+-----------------------------+

|     SISTEMA OPERATIVO       |

+-----------------------------+

              |

              ↓

+-----------------------------+

|          HARDWARE           |

+-----------------------------+`}</pre>
</div>

El sistema operativo permite que los programas utilicen recursos como:

- CPU.

- Memoria RAM.

- Disco duro.

- Teclado.

- Mouse.

- Pantalla.

- Red.

- Impresoras.

- Dispositivos USB.

Sin un sistema operativo, el usuario tendría que controlar directamente el hardware, lo cual sería extremadamente complicado.

## 2. ¿Por qué es importante un Sistema Operativo?
El sistema operativo es importante porque permite que el hardware sea utilizado de forma organizada.

Entre sus funciones principales se encuentran:

- Controlar el procesador.

- Administrar la memoria.

- Controlar dispositivos.

- Administrar archivos.

- Ejecutar programas.

- Proporcionar seguridad.

- Organizar usuarios.

- Controlar conexiones de red.

- Gestionar procesos.

Por ejemplo, cuando abrimos un navegador, el sistema operativo debe:

1\. Localizar el programa en el disco.

2\. Cargarlo en memoria.

3\. Crear un proceso.

4\. Asignarle tiempo de CPU.

5\. Permitir que utilice la red.

6\. Controlar los archivos que necesita.

7\. Mostrar la interfaz en pantalla.

Todo esto ocurre automáticamente.
---
## 3. Objetivos principales de un Sistema Operativo
Los sistemas operativos buscan cumplir principalmente tres objetivos.
### 3.1 Comodidad
El sistema debe facilitar el uso de la computadora.

Por ejemplo, en lugar de que el usuario controle manualmente sectores del disco, puede utilizar archivos y carpetas.
### 3.2 Eficiencia
El sistema operativo debe aprovechar correctamente los recursos.

Por ejemplo:

<div className="u1-diagram">
  <pre>{`CPU

RAM

Disco

Red

Dispositivos`}</pre>
</div>

El sistema debe administrar estos recursos para evitar desperdicio.
### 3.3 Capacidad de evolución
El sistema operativo debe poder adaptarse a nuevos dispositivos y tecnologías.

Por ejemplo:

- Nuevos procesadores.

- Nuevas tarjetas gráficas.

- Nuevos sistemas de almacenamiento.

- Nuevos dispositivos USB.

- Nuevas tecnologías de red.
---
## 4. Funciones principales del Sistema Operativo
Un sistema operativo realiza muchas tareas.

Las más importantes son:
### Gestión de procesos
Controla los programas que se están ejecutando.

Incluye:

- Creación de procesos.

- Planificación.

- Suspensión.

- Finalización.

- Sincronización.

- Comunicación.
### Gestión de memoria
Administra la memoria RAM.

Decide:

- Qué proceso utiliza memoria.

- Cuánta memoria recibe.

- Cuándo liberar memoria.

- Cómo proteger la memoria entre procesos.
### Gestión de archivos
Permite organizar información mediante:

- Archivos.

- Carpetas.

- Directorios.

- Permisos.

- Sistemas de archivos.
### Gestión de dispositivos
Controla dispositivos mediante controladores o drivers.

Por ejemplo:

- Impresoras.

- Teclados.

- Mouse.

- Tarjetas de red.

- Discos.

- Memorias USB.
### Gestión de seguridad
Controla:

- Usuarios.

- Contraseñas.

- Permisos.

- Acceso a archivos.

- Acceso a dispositivos.

- Privilegios.

## 5. El Kernel o Núcleo
El **Kernel** es la parte central del sistema operativo.

Se encarga de controlar directamente los recursos más importantes de la computadora.

Podemos representarlo así:

<div className="u1-diagram">
  <pre>{`Aplicaciones

     |

     ↓

+-------------+

|   KERNEL    |

+-------------+

     |

     ↓

Hardware`}</pre>
</div>

El Kernel normalmente controla:

- CPU.

- Memoria.

- Procesos.

- Dispositivos.

- Interrupciones.

- Entrada y salida.

- Llamadas al sistema.

El Kernel se ejecuta con privilegios elevados.
---
## 6. Diferencia entre Sistema Operativo y Kernel
Aunque muchas veces se utilizan como si fueran lo mismo, no son exactamente iguales.

| Sistema Operativo | Kernel |

|---|---|

| Incluye múltiples componentes | Es el núcleo principal |

| Puede incluir interfaz gráfica | No necesariamente incluye interfaz |

| Incluye herramientas y servicios | Controla recursos básicos |

| Es el entorno completo | Es una parte del sistema |

Por ejemplo, un sistema operativo puede incluir:

<div className="u1-diagram">
  <pre>{`Sistema Operativo

│

├── Kernel

├── Drivers

├── Sistema de archivos

├── Servicios

├── Interfaz gráfica

└── Utilidades`}</pre>
</div>

## 8. Gestión del Procesador
La CPU es uno de los recursos más importantes.

El sistema operativo debe decidir qué programa puede utilizarla.

Cuando existen varios programas abiertos:

  <pre>{`Chrome

Word

Terminal`}</pre>
</div>

todos necesitan tiempo de CPU.

El sistema operativo utiliza un planificador para decidir quién se ejecuta primero.

Ejemplo:

<div className="u1-diagram">

P3 → espera

P4 → espera`}</pre>
</div>

<div className="u1-diagram">

La memoria RAM es un recurso limitado.

El sistema operativo debe controlar:

- Qué zonas están ocupadas.

- Qué zonas están libres.

- Qué proceso utiliza cada zona.

- Cuándo liberar memoria.

- Cómo evitar accesos no autorizados.

Ejemplo:

<div className="u1-diagram">

+----------------------+

+----------------------+

| Proceso C            |

+----------------------+

| Espacio libre        |

+----------------------+`}</pre>
</div>

## 10. Gestión de Almacenamiento
El sistema operativo también administra dispositivos como:

- HDD.

- SSD.

- Memorias USB.

- Tarjetas SD.

El usuario normalmente no trabaja directamente con sectores físicos.

En su lugar utiliza:

- Archivos.

- Carpetas.

- Directorios.

Por ejemplo:

<div className="u1-diagram">
  <pre>{`Documentos/

├── tarea.pdf

├── informe.docx

└── notas.txt`}</pre>
</div>

El sistema operativo traduce esta organización lógica a ubicaciones físicas en el dispositivo.
---
## 11. Sistemas de Archivos
Un sistema de archivos es la forma en que el sistema operativo organiza la información almacenada.

Algunos ejemplos son:

- NTFS.

- FAT32.

- exFAT.

- ext4.

- APFS.

El sistema de archivos puede administrar:

- Nombre de archivos.

- Tamaño.

- Ubicación.

- Permisos.

- Fechas.

- Propietarios.
---
## 12. Gestión de Entrada y Salida
La entrada y salida se conoce como **E/S** o **I/O**.

Ejemplos de dispositivos de entrada:

- Teclado.

- Mouse.

- Micrófono.

- Cámara.

Ejemplos de dispositivos de salida:

- Monitor.

- Impresora.

- Bocinas.

Algunos dispositivos pueden realizar ambas funciones.

Por ejemplo:

- Disco duro.

- Tarjeta de red.

- Pantalla táctil.
---

Un **driver** es un programa que permite al sistema operativo comunicarse con un dispositivo.

- Driver de video.

- Driver de impresora.

- Driver de red.

- Driver USB.
---
## 14. Modos de operación de la CPU
Para mejorar la seguridad, los procesadores utilizan diferentes niveles de privilegio.

Los dos más conocidos son:

- Modo Usuario.

- Modo Kernel.
---
## 15. Modo Usuario
El **Modo Usuario** es donde normalmente se ejecutan las aplicaciones.

Tiene privilegios limitados.

Por ejemplo, una aplicación normalmente no puede:

- Acceder directamente a toda la memoria.

- Controlar directamente el procesador.

- Modificar estructuras internas del kernel.

- Acceder directamente a determinados dispositivos.

Esto mejora la seguridad.

Si una aplicación falla, en muchos casos solamente se cierra esa aplicación.
---
## 16. Modo Kernel
El **Modo Kernel** tiene privilegios elevados.

El sistema operativo puede realizar operaciones que no están permitidas a las aplicaciones normales.

Por ejemplo:

- Configurar dispositivos.

- Administrar memoria.

- Controlar interrupciones.

- Modificar tablas internas.

- Administrar procesos.
---
## 17. Comparación entre Modo Usuario y Modo Kernel
| Modo de ejecución | Privilegios | Uso |

|---|---|---|

| Modo Usuario | Limitados | Aplicaciones |

| Modo Kernel | Elevados | Núcleo del sistema |

Podemos representarlo de la siguiente manera:

<div className="u1-diagram">
  <pre>{`+----------------------+

|    MODO USUARIO      |

| Navegador            |

| Editor               |

| Juegos               |

+----------------------+

          |

          ↓

     System Call

          |

          ↓

+----------------------+

|    MODO KERNEL       |

| Sistema Operativo    |

+----------------------+

          |

          ↓

       Hardware`}</pre>
</div>
---
## 18. Protección del sistema
La separación entre modo usuario y modo kernel evita que las aplicaciones tengan control total del equipo.

Por ejemplo, si cualquier programa pudiera modificar la memoria del kernel, podría:

- Bloquear el sistema.

- Eliminar información.

- Interferir con otros programas.

- Obtener acceso no autorizado.

Por eso se utilizan diferentes niveles de privilegio.
---
## 19. Llamadas al Sistema
Las **Llamadas al Sistema**, conocidas como **System Calls**, permiten que un programa solicite un servicio al sistema operativo.

Las aplicaciones no acceden directamente al hardware.

En lugar de eso, realizan solicitudes al kernel.

## 24. Interrupciones
Una **interrupción** es una señal que indica al procesador que debe atender un evento.

Por ejemplo:

- Se presionó una tecla.

- Llegó información de red.

- Terminó una operación de disco.

- Se activó un temporizador.

Podemos representarlo así:

<div className="u1-diagram">
  <pre>{`CPU ejecutando programa

        |

        ↓

   INTERRUPCIÓN

        |

        ↓

Sistema Operativo

        |

        ↓

Atiende evento

        |

        ↓

Continúa ejecución`}</pre>
</div>
---
## 25. Tipos de interrupciones
Existen diferentes tipos de interrupciones.
### Interrupciones de hardware
Provienen de dispositivos físicos.

Por ejemplo:

- Teclado.

- Mouse.

- Disco.

- Tarjeta de red.
### Interrupciones de software
Pueden generarse mediante instrucciones o eventos del software.
### Excepciones
Ocurren cuando la CPU detecta alguna condición especial.

Por ejemplo:

- División entre cero.

- Instrucción inválida.

- Acceso incorrecto a memoria.
---
## 26. Importancia de las interrupciones
Las interrupciones permiten que la CPU no tenga que revisar constantemente todos los dispositivos.

En lugar de eso, los dispositivos avisan cuando necesitan atención.

Esto mejora la eficiencia.
---
## 27. Evolución histórica de los Sistemas Operativos
Los sistemas operativos han evolucionado junto con las computadoras.

Podemos dividir su historia en diferentes etapas.
---
## 28. Primera generación de computadoras
Las primeras computadoras no tenían sistemas operativos modernos.

Los programas debían cargarse manualmente.

Características:

- Uso de lenguaje máquina.

- No existía multitarea.

- Programación muy difícil.

- Uso de tarjetas perforadas en algunos sistemas.
---
## 29. Sistemas por lotes
Posteriormente aparecieron los sistemas por lotes o **Batch Systems**.

Los trabajos se agrupaban y se ejecutaban uno después de otro.

Ejemplo:

<div className="u1-diagram">
  <pre>{`Trabajo 1

   ↓

Trabajo 2

   ↓

Trabajo 3

   ↓

Trabajo 4`}</pre>
</div>

El usuario no interactuaba directamente con el programa durante su ejecución.
---
## 30. Multiprogramación
La multiprogramación permitió mantener varios programas en memoria.

Ejemplo:

<div className="u1-diagram">
  <pre>{`RAM

+--------------------+

| Sistema Operativo  |

+--------------------+

| Programa A         |

+--------------------+

| Programa B         |

+--------------------+

| Programa C         |

+--------------------+`}</pre>
</div>

Si un programa esperaba una operación de E/S, otro podía utilizar la CPU.

Esto aumentó la eficiencia.
---
## 31. Sistemas de tiempo compartido
Los sistemas de tiempo compartido permitieron que varios usuarios utilizaran una misma computadora.

El procesador repartía pequeñas cantidades de tiempo entre diferentes tareas.

Ejemplo:

<div className="u1-diagram">
  <pre>{`Tiempo →

Usuario A | Usuario B | Usuario C | Usuario A | Usuario B`}</pre>
</div>

Esto permitió desarrollar sistemas interactivos.
---
## 32. Computadoras personales
Con la aparición de las computadoras personales surgieron sistemas operativos orientados al usuario.

Ejemplos históricos:

- MS-DOS.

- Windows.

- Mac OS.

- Linux.

Con el tiempo estos sistemas incorporaron:

- Interfaces gráficas.

- Multitarea.

- Redes.

- Seguridad.

- Internet.
---
## 33. Sistemas operativos modernos
Actualmente los sistemas operativos deben administrar sistemas mucho más complejos.

Por ejemplo:

- Procesadores multinúcleo.

- Computación en la nube.

- Virtualización.

- Dispositivos móviles.

- Redes.

- GPU.

- Grandes cantidades de memoria.

Ejemplos actuales:

- Windows.

- GNU/Linux.

- macOS.

- Android.

- iOS.
---
## 34. Tipos de Sistemas Operativos
Existen diferentes tipos de sistemas operativos.
### Sistemas de escritorio
Diseñados para computadoras personales.

Ejemplos:

- Windows.

- macOS.

- Linux.
### Sistemas móviles
Diseñados para teléfonos y tabletas.

Ejemplos:

- Android.

- iOS.
### Sistemas de servidor
Diseñados para proporcionar servicios.

Ejemplos:

- Linux Server.

- Windows Server.

- Unix.
### Sistemas embebidos
Se utilizan en dispositivos especializados.

Ejemplos:

- Routers.

- Automóviles.

- Electrodomésticos.

- Equipos industriales.
---
## 35. Sistemas de tiempo real
Los sistemas de tiempo real deben responder dentro de límites de tiempo determinados.

Se utilizan en situaciones donde una respuesta tardía puede causar problemas.

Ejemplos:

- Sistemas industriales.

- Equipos médicos.

- Sistemas automotrices.

- Control aéreo.

- Robótica.
---
## 36. Sistemas distribuidos
Un sistema distribuido utiliza varias computadoras conectadas para realizar tareas.

Ejemplo:

---
## 37. Sistemas de red
Los sistemas operativos de red permiten administrar recursos compartidos entre diferentes computadoras.

Por ejemplo:

- Archivos.

- Impresoras.

- Usuarios.

- Servidores.

- Conexiones.
---
## 38. Sistemas multiprocesador
Un sistema multiprocesador utiliza más de una unidad de procesamiento.

Hoy en día es común encontrar CPUs con varios núcleos.

Ejemplo:

<div className="u1-diagram">

---
## 39. Multitarea
La multitarea permite ejecutar diferentes programas durante el mismo periodo de tiempo.

Por ejemplo:

<div className="u1-diagram">
  <pre>{`Navegador

+

Editor de texto

+

+

</div>

El sistema operativo cambia entre tareas rápidamente.

En procesadores multinúcleo, algunas tareas pueden ejecutarse realmente en paralelo.
---
## 40. Multiusuario
Un sistema multiusuario permite que diferentes usuarios utilicen los recursos de una computadora.

Cada usuario puede tener:

- Cuenta.

- Contraseña.

- Archivos.

- Permisos.

- Configuración.

Linux y Unix son ejemplos de sistemas con fuertes características multiusuario.
---

El sistema operativo debe proteger:

- Datos.

- Usuarios.

- Procesos.

- Memoria.

- Archivos.

- Red.

- Dispositivos.

Entre los mecanismos utilizados se encuentran:

- Contraseñas.

- Permisos.

- Cuentas.

- Cifrado.

- Control de acceso.

- Protección de memoria.
---

## 44. Arquitecturas del Kernel
Existen diferentes formas de organizar internamente un kernel.

Las principales son:

1\. Monolítica.

2\. Microkernel.

3\. Híbrida.

4\. Modular.
---
## 45. Kernel Monolítico
En un kernel monolítico, muchos servicios del sistema se ejecutan en modo kernel.

Ejemplo:

<div className="u1-diagram">
  <pre>{`+--------------------------------+

|          KERNEL                |

| Procesos                       |

| Memoria                        |

| Drivers                        |

| Archivos                       |

| Red                            |

+--------------------------------+`}</pre>
</div>
### Ventajas
- Buen rendimiento.

- Comunicación rápida entre componentes.
### Desventajas
- Una falla en un componente puede afectar gran parte del sistema.

- Puede ser más complejo de mantener.

Linux utiliza un kernel monolítico con diseño modular.
---
## 46. Microkernel
Un microkernel intenta mantener dentro del kernel solamente las funciones esenciales.

Por ejemplo:

<div className="u1-diagram">
  <pre>{`Modo Usuario

+----------------------------+

| Drivers                    |

| Sistemas de archivos       |

| Servicios                  |

+----------------------------+

Modo Kernel

+----------------------------+

| IPC                        |

| Planificación              |

| Gestión básica de memoria  |

+----------------------------+`}</pre>
</div>
### Ventajas
- Mejor aislamiento.

- Mayor modularidad.

- Puede mejorar la estabilidad.
### Desventajas
- La comunicación entre componentes puede generar sobrecarga.
---
## 47. Kernel Híbrido
Un kernel híbrido combina características de arquitecturas monolíticas y microkernel.

Busca obtener:

- Buen rendimiento.

- Modularidad.

- Flexibilidad.

Windows NT y XNU utilizan diseños considerados híbridos.
---
## 48. Kernel Modular
Un kernel modular permite cargar y descargar componentes según sea necesario.

Estos componentes pueden llamarse módulos.

Por ejemplo:

<div className="u1-diagram">
  <pre>{`Kernel

 |

 +--- Módulo de red

 +--- Módulo USB

 +--- Módulo de sonido

 +--- Módulo de sistema de archivos`}</pre>
</div>

Esto permite ampliar funcionalidades sin recompilar todo el kernel.

## 78. Preguntas de repaso### 1. ¿Qué es un Sistema Operativo?
Es el software encargado de administrar el hardware y proporcionar servicios a los programas.

Es el núcleo del sistema operativo y controla recursos fundamentales como CPU, memoria y dispositivos.
### 3. ¿Qué diferencia existe entre modo usuario y modo kernel?
El modo usuario tiene privilegios limitados, mientras que el modo kernel tiene acceso privilegiado al sistema.

Es un mecanismo mediante el cual una aplicación solicita un servicio al kernel.

Es un software que permite al sistema operativo comunicarse con un dispositivo.
### 6. ¿Qué función tiene la memoria RAM?
Almacena temporalmente programas y datos que están siendo utilizados.

Es una señal que permite solicitar atención del procesador.
### 8. ¿Qué es la multiprogramación?
Es una técnica que mantiene varios programas disponibles para aprovechar mejor la CPU.
### 9. ¿Qué es la multitarea?
Es la capacidad del sistema operativo para administrar diferentes tareas durante el mismo periodo.
### 10. ¿Qué es un sistema de archivos?
Es el mecanismo utilizado para organizar la información almacenada.

## 87. Resumen general
Un sistema operativo es el software que administra los recursos de una computadora y permite que los programas puedan ejecutarse correctamente.

Entre sus funciones principales se encuentran la gestión de procesos, memoria, almacenamiento, dispositivos, seguridad y usuarios.

El kernel representa la parte central del sistema y se ejecuta con privilegios elevados.

Las aplicaciones normalmente funcionan en modo usuario y utilizan llamadas al sistema para solicitar servicios al kernel.

La separación entre modo usuario y modo kernel mejora la estabilidad y seguridad del sistema.

Los sistemas operativos también utilizan interrupciones para responder a eventos, drivers para controlar dispositivos y sistemas de archivos para organizar la información.

A lo largo del tiempo, los sistemas operativos han evolucionado desde sistemas muy simples hasta plataformas capaces de administrar múltiples procesadores, usuarios, redes, máquinas virtuales y grandes cantidades de información.
---
## 88. Conclusión
Los sistemas operativos son una parte fundamental de cualquier computadora moderna.

Su función principal es actuar como intermediario entre las aplicaciones y el hardware, facilitando el uso de los recursos y evitando que los programas tengan que controlar directamente los componentes físicos.

El sistema operativo administra recursos como la CPU, memoria, almacenamiento y dispositivos. Además, proporciona mecanismos de seguridad, llamadas al sistema, control de procesos y protección mediante diferentes niveles de privilegio.

Comprender conceptos como kernel, modo usuario, modo kernel, drivers, llamadas al sistema, interrupciones y arquitecturas del kernel es fundamental para avanzar hacia temas más complejos relacionados con procesos, concurrencia, memoria e interbloqueos.
---
